## 🧭 من أنا

من البحرين، أبني بالذكاء الاصطناعي **أنظمة كاملة لا صفحات تجريبية**: أفكّرها، أصمّمها، أكتب كودها وواجهاتها وقواعد بياناتها، ثم أُخضعها لحملات ضغط، وأطلقها، وأرعاها وهي حية في السوق.

هذه ليست مهنة أكتب عنها — إنها **طريقة عمل موثّقة بالأرقام**: على GitHub منذ يوليو 2026، وفي أول ثلاثة أشهر أنجزت بالبرمجة بالذكاء الاصطناعي (Vibe Coding) ما كان يستغرق فرقًا كاملة: **14 مستودعًا** لمنتجات حية، **أكثر من 500 إيداع برمجي (commit)** بجولات مرقّمة موثقة، و**18+ طلب دمج** مفتوح المصدر.

معظم إنتاجي يقع في مستودعات خاصة — لأنها منتجات تجارية حية يدفع الناس مقابلها فعلاً. ما تراه هنا واجهة المصنع، والمصنع خلفها يعمل بكامل طاقته.

## 🤖 تجربة الوكلاء — قسم الجودة الذي لا ينام

عادتي التي أفخر بها: أُدير **تجارب وكلاء** منظمة على منتجاتي الحية كأنها قسم جودة مستقل:

- **3 جولات محكومة** بمنهجية مكتوبة قبل التشغيل، وتقارير تُولد آليًا كل ساعة
- **46,704 فعلًا** نفذها الوكلاء على منتج حقيقي، بتغطية **304 من 451** مسارًا حرجًا
- تقرير نهائي من **21,352 سطرًا** يبنى بسكربت من الملفات الخام — لا يد بشرية تلوث الأرقام
- الوكلاء اكتشفوا **ثغرات منتج حقيقية** سبقت عيني: جذر انهيار نادر تحت التزامن، وسباق دفع مزدوج — حُسمت جميعها بالأدلة الحية وأصبحت إصلاحات مرقمة
- **مشرف مرن** يعيد الخادم والمنسق آليًا ويستأنف من أول فعل مسجل — التجربة نفسها تبنى كأنها نظام إنتاجي

> لا أكتفي باستخدام الذكاء الاصطناعي في كتابة الكود — بل أطلقه على منتجاتي **ليكسرها قبل أن يكسرها الزبون**.

- 🌍 **العربية أولًا** — كل منتجاتي تُبنى RTL من اليوم الأول، وتُترجم حين يقتضيها سوقها (بلغت إحداها 5 لغات تخدم سوق البحرين بلغاته الفعلية)

## 🧭 Who I Am

From Bahrain, I use AI to build **complete systems — not demo pages**: I conceive them, design them, write their code, interfaces, and databases, then put them through load campaigns, launch them, and keep caring for them while they run alive in the market.

This is not a profession I merely write about — it is a **working method documented in numbers**: on GitHub since July 2026, and in my first three months of Vibe Coding I shipped what used to take whole teams: **14 repositories** of live products, **500+ commits** in numbered, documented rounds, and **18+ open-source pull requests**.

Most of my output lives in private repositories — because they are commercial products people actually pay for. What you see here is the shopfront; the factory behind it is running at full capacity.

## ⚙️ How I Work With Systems

| Principle | What it looks like on the ground |
| --- | --- |
| 🔄 **Numbered rounds** | Every change is a documented round with a number and version — from V1 to V41, and D22 to D39 — with a work log anyone who comes after can read |
| 📊 **Honest counting** | Numbers are built from the source of truth only; I rebuilt the coverage counter because a bug was silently zeroing it — what is not measured honestly does not exist |
| 📸 **Live evidence** | Every fix is documented with browser captures from live production itself, not from staging alone |
| 🔬 **Root cause by counter-proof** | Before I believe a cause, I reproduce the bug on an identical copy and isolate the variable — counter-proof before belief |
| ⚖️ **Production mirrors staging** | The live rule must equal the experimental one fully — otherwise the fix is not finished yet |
| 🌊 **Load before customers** | External load campaigns before every launch: 100 concurrent connections, p99 = 993ms, one hour of endurance with zero errors and no memory leaks |
| 🧹 **Clean for release, original for memory** | A sanitized release repository with a whitelist and a hardened history, and a backup pipeline that reached wave 67 under a documented purification policy |
| 🔐 **Secrets are not history** | No tokens or signing keys in git history — and the purge itself is documented the way features are |

## 🤖 Agent Trials — The QA Department That Never Sleeps

The habit I am proudest of: I run **structured agent trials** on my live products as if they were an independent QA department:

- **3 governed rounds** with a methodology written before execution, and reports auto-generated every hour
- **46,704 actions** executed by agents on a real product, covering **304 of 451** critical paths
- A final report of **21,352 lines** built by script from the raw files — no human hands touch the numbers
- The agents found **real product flaws** before my eyes: a rare crash root under concurrency, and a double-push race — all settled with live evidence and turned into numbered fixes
- A **resilient supervisor** restarts the server and coordinator automatically and resumes from the first logged action — the experiment itself is built like a production system

> I do not just use AI to write code — I unleash it on my own products **to break them before a customer does**.

## 🧪 My Coding Habits

- 📓 **A permanent work log** — every project has a `worklog.md` documenting rounds, what broke, and why; memory gets deducted from me, so I write it all down
- 🗺️ **The platform map governs access** — a "screens × roles × actions" matrix (1,135+ lines): a page is visible because the role owns it, not the other way around
- 🩺 **A graded health battery** — every platform carries a context-aware health battery scored in points (I raised one from 68 to 83 in a single round)
- 🧾 **Legal packs born from the identity itself** — privacy policy (1,682 lines), terms of use (1,617), and 32 contracts unified in branding, all A4-printable
- 💸 **The fils-precision contract** — the Bahraini dinar in three decimal places across every layer; the finance engine's codename is "one waterfall of truth, no fils lost"
- 🚨 **Incidents documented even when unresolved** — the stubborn incident is recorded with its investigation evidence as it is; hiding ignorance is more dangerous than the bug itself
- 🤝 **The owner's order as a document** — every instruction from the product owner is executed tagged "by owner's order" and pinned in the round log — the client is a partner in the log, not a source of noise
- 🧰 **Tools before features** — an icon checker, a link validator (zero broken links across a 1,037-page audit chain), and browser verification guides: tools I built to serve the product itself
