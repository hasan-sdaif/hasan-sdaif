## 💼 مشروعي التجاري — [tafseeli.app](https://tafseeli.app)

**تفصيلي** — منصة سحابية لإدارة محلات الخياطة والتفصيل في البحرين:
قياسات الزبائن محفوظة بدقة مدى الحياة، طلبات وورش عمل، فواتير ضريبية وتحصيل، متجر إلكتروني خاص بكل محل، وتقارير أعمال لحظية — تعمل من المتصفح ومن تطبيق الأندرويد مباشرة.

## 🧰 البنية التقنية التي أعمل بها

- **الإطار الأساسي:** Next.js (App Router) · React · TypeScript · Tailwind CSS
- **الاستضافة والنشر:** [Vercel](https://vercel.com) و[Netlify](https://netlify.com) — نشر مستمر بضغطة واحدة
- **قواعد البيانات:** [Turso](https://turso.tech) — قاعدة بيانات SQLite موزعة على الحافة، سريعة أينما كان المستخدم
- **البريد الإلكتروني:** [Resend](https://resend.com) للإرسال البرمجي الموثوق + [ImproveMX](https://improvmx.com) لتوجيه بريد النطاقات
- **الأندرويد:** WebView + JavaScript Interface بجافا الأصلية

### 🇬🇧 English

AI-powered software developer (**Vibe Coding**) — I build complete digital products end-to-end: web apps, administrative systems for education and commerce, community classification platforms, and Android WebView apps with native Java bridges.

My core stack is **Next.js + TypeScript + Tailwind CSS**, deployed on **Vercel** and **Netlify**, with **Turso** as the edge database and **Resend + ImproveMX** for email. My commercial project is [tafseeli.app](https://tafseeli.app) — a cloud platform for tailoring shops in Bahrain (customer measurements, orders, tax invoices, a storefront per shop, live reports — in the browser or the Android app).

I also contribute to open source: 18+ pull requests bringing full Arabic UI support (catalogs, font chains, Microsoft/Adobe/AutoCAD Arabic terminology) to the Rust/egui Craft apps family.
