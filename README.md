## أهلاً 👋

أنا حسن، مهتم بتعريب البرمجيات مفتوحة المصدر. أؤمن أن المستخدم العربي يستحق واجهة بلغته، لا واجهة مترجمة آلياً بلا روح.

### ما أعمل عليه
- ترجمة واجهات تطبيقات **Crafting Apps** (Photocraft وWordCraft وFilmCraft وLightCraft وغيرها) إلى العربية الفصحى، مع التزام إخراج النص العربي بشكل صحيح حيث تتيح ذلك محرّكات الواجهة.
- الالتزام بمصطلحات النسخ العربية الرسمية للبرامج المعروفة (مايكروسوفت أوفيس، فوتوشوب، أوتوكاد...) حتى يجد المستخدم ما تعوّد عليه.
- ترجمة الوثائق العامة (README) إلى العربية.

### كيف أعمل
أترجم من المعنى لا من الحرف، أستخدم قواعد الجمع العربية كاملة (صفر، واحد، اثنان، قلة، كثرة، غيرها)، وأحافظ على سلامة النصوص البرمجية والاختبارات. التعليقات على المصطلحات موضع ترحيب دائماً — التعريب عمل جماعي.

### English

Arabic localization contributor for open-source software — currently translating the Crafting Apps family (photocraft, filmcraft, lightcraft, pdfcraft, wordcraft, vectorcraft, effectcraft, designcraft, gridcraft, cadcraft, deckcraft, soundcraft, craft-launcher) into Modern Standard Arabic, keeping the English source untouched at the code level and translating at display time so nothing breaks. I follow the official Arabic terminology of the products these apps reimplement (MS Office, Photoshop, AutoCAD, Premiere…). Terminology feedback is always welcome.
